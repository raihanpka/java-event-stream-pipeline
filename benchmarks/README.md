# Benchmarks

This directory contains reproducible benchmark results for the Bromo event pipeline. All measurements are collected from controlled test environments with documented hardware specifications. The goal is to provide transparent, verifiable performance data for anyone evaluating or tuning Bromo.

## Structure

```
benchmarks/
├── README.md                     # This file
├── 001-throughput-ingestion/     # Event ingestion throughput tests
│   ├── REPORT.md                 # Test methodology, environment, results
│   ├── hardware.txt              # CPU, RAM, disk, JVM version
│   ├── config/                   # Bromo configuration used during test
│   │   ├── application.yml
│   │   └── docker-compose.yml
│   └── data/                     # Raw telemetry dumps
│       ├── prometheus-metrics.json
│       ├── container-stats.csv
│       └── k6-results.json
├── 002-latency-end-to-end/       # End-to-end latency measurements
├── 003-memory-profile/           # Memory usage under load
├── 004-consumer-lag/             # Kafka consumer lag at various rates
├── 005-native-vs-jvm/            # JVM mode vs GraalVM native comparison
└── template/                     # Template for new benchmark reports
    └── REPORT.md
```

## Methodology

Every benchmark follows the same methodology:

1. Infrastructure is provisioned using the Docker Compose or Helm configuration committed in the test's `config/` directory.
2. Hardware specifications are documented in `hardware.txt` (CPU model, core count, RAM, disk type, OS, JVM version).
3. Load is generated by the bromo-simulator service or k6 scripts from `load-tests/k6/`.
4. Metrics are collected from Prometheus (scraped every 10 seconds), Docker stats (collected every 5 seconds), and k6 output.
5. Each test is run three times. Results show the median, p95, and p99 values across runs.
6. Raw data is committed alongside the report. Nothing is summarized without the source data.

## How to Run a Benchmark

```bash
# 1. Start Bromo with the benchmark configuration
docker compose -f benchmarks/001-throughput-ingestion/config/docker-compose.yml up -d

# 2. Run the load test
k6 run load-tests/k6/ingestion-throughput.js \
  -e BASE_URL=http://localhost:8081 \
  -e DURATION=300s \
  -e RATE=5000

# 3. Export metrics
curl http://localhost:9090/api/v1/query_range?query=... > data/prometheus-metrics.json

# 4. Document results in REPORT.md
```
